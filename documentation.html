Presentation du projet

TodoItems API est une API REST developpee avec ASP.NET Core 9.0. Elle permet la gestion de taches (todo items) avec authentification JWT et autorisation par roles (admin / user).

🔒

Authentification JWT

Inscription, connexion et tokens signes avec expiration configurable.

👥

Autorisation par roles

Deux roles : admin (CRUD complet) et user (lecture seule).

📄

Swagger / OpenAPI

Interface interactive pour tester tous les endpoints depuis le navigateur.

🐳

Support Docker

Build multi-stage optimise, Docker Compose inclus pour un deploiement rapide.

Lancer le projet

Option 1 — En local (le plus simple)

Aucune configuration requise Le secret JWT de developpement est pre-configure dans appsettings.Development.json. L'application fonctionne immediatement apres clonage.
1
Cloner le depot
git clone <url-du-repo>
2
Lancer l'API
cd "API web"
dotnet run
3
Ouvrir Swagger
http://localhost:5284/swagger

Option 2 — Via Docker

Seule etape manuelle Creer le fichier .env depuis .env.example et y definir JWT_SECRET_KEY.
1
Cloner le depot et creer le fichier d'environnement
git clone <url-du-repo>
cp .env.example .env
2
Ouvrir .env et definir la cle secrete (min. 32 caracteres)
JWT_SECRET_KEY=mon-secret-securise-minimum-32-caracteres
JWT_EXPIRATION_MINUTES=60
ASPNETCORE_ENVIRONMENT=Development
3
Lancer via Docker Compose
docker-compose up --build
4
Ouvrir Swagger
http://localhost:8080/swagger

Tester l'API (pas a pas via Swagger)

1
Ouvrir http://localhost:5284/swagger
2
Creer un compte admin — POST /api/auth/register → Try it out 
{
  "username": "admin",
  "password": "Test123!",
  "role": "admin"
}
Reponse attendue : 201 Created
3
Se connecter — POST /api/auth/login → copier le champ token dans la reponse 
{
  "username": "admin",
  "password": "Test123!"
}
4
S'authentifier — cliquer sur le bouton Authorize (icone cadenas en haut a droite), coller le token, valider
5
Tester les endpoints — GET, POST, PUT, DELETE tous disponibles selon le role

Systeme de roles

🔴 Role admin — CRUD complet

Peut lire, creer, modifier et supprimer des taches. S'inscrire avec "role": "admin".

🟢 Role user — Lecture seule

Peut uniquement lire les taches (GET). S'inscrire avec "role": "user".

Actionuseradmin

Depannage

L'app ne demarre pas — "JWT_SECRET_KEY is not configured" Mode Production sans cle JWT definie. Lancer avec ASPNETCORE_ENVIRONMENT=Development ou definir export JWT_SECRET_KEY=votre-cle-32-chars-min.
401 Unauthorized Header Authorization manquant, token expire, ou format incorrect. Format attendu : Bearer <token>. Se reconnecter via /api/auth/login.
403 Forbidden sur creation / modification / suppression Le compte a le role user. Creer un compte avec "role": "admin".
