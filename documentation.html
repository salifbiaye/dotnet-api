Presentation du projet

TodoItems API est une API REST developpee avec ASP.NET Core 9.0. Elle permet la gestion de taches avec authentification JWT, autorisation par roles, et persistance des donnees dans MongoDB.

🔒

Authentification JWT

Inscription, connexion et tokens signes avec expiration configurable.

👥

Autorisation par roles

Deux roles : admin (CRUD complet) et user (lecture seule).

📄

Swagger / OpenAPI

Interface interactive pour tester tous les endpoints depuis le navigateur.

🐳

Docker + MongoDB

Une seule commande lance l'API et la base de donnees ensemble.

Instructions pour lancer le projet

🐳 Via Docker — Recommande (2 commandes seulement)

Aucune configuration requise Le JWT_SECRET_KEY et la connexion MongoDB sont deja configures dans le docker-compose.yml. Aucun fichier .env a creer.
1
Cloner le depot
git clone https://github.com/salifbiaye/dotnet-api
cd dotnet-api
2
Lancer l'API + MongoDB 
docker-compose up -d
Docker telecharge MongoDB, construit l'API, et demarre tout automatiquement.
MongoDB est pret avant que l'API demarre (healthcheck configure).
3
Ouvrir Swagger
http://localhost:8080/swagger
Pour arreter docker-compose down — Les donnees MongoDB persistent dans un volume Docker.

💻 En local avec dotnet run

Prerequis : .NET 9.0 SDK + MongoDB accessible sur 127.0.0.1:27017 (via Docker : docker run -d -p 27017:27017 mongo:7)

1
Cloner et lancer
git clone https://github.com/salifbiaye/dotnet-api
cd "dotnet-api/API web"
dotnet run
2
Swagger disponible sur
http://localhost:5284/swagger

Tester l'API (pas a pas via Swagger)

1
Ouvrir http://localhost:8080/swagger
2
Creer un compte admin — POST /api/auth/register → Try it out 
{
  "username": "admin",
  "password": "Test123!",
  "role": "admin"
}
Reponse attendue : 201 Created
3
Se connecter — POST /api/auth/login → copier le champ token dans la reponse 
{
  "username": "admin",
  "password": "Test123!"
}
4
S'authentifier — cliquer sur Authorize (icone cadenas), coller le token, valider
5
Tester les endpoints — GET, POST, PUT, DELETE selon le role

Reference API

Authentification (sans token)

MethodeEndpointDescription
POST/api/auth/registerCreer un compte utilisateur

Todo Items (token requis)

MethodeEndpointDescriptionRole requis
GET/api/todoitemsLister toutes les tachesuser ou admin
GET/api/todoitems/{id}Recuperer une tache par IDuser ou admin
POST/api/todoitemsCreer une tacheadmin
PUT/api/todoitems/{id}Modifier une tacheadmin
DELETE/api/todoitems/{id}Supprimer une tacheadmin

Health Checks (sans token)

MethodeEndpointDescription
GET/healthVerification basique (toujours 200 OK)
GET/readyVerification disponibilite MongoDB

Systeme de roles

🔴 Role admin — CRUD complet

Peut lire, creer, modifier et supprimer des taches. S'inscrire avec "role": "admin".

🟢 Role user — Lecture seule

Peut uniquement lire les taches (GET). S'inscrire avec "role": "user".
